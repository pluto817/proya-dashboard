# 珀莱雅可视化大屏

基于Uplift因果推断的珀莱雅精准营销智能决策系统

## 项目简介

本项目是一个数据可视化大屏，用于展示珀莱雅的营销数据和分析结果。主要功能包括：

- 首页总览：展示核心指标和关键数据
- 用户洞察：分析用户行为和偏好
- Uplift决策：基于因果推断的营销策略优化
- 购物篮分析：商品关联分析和相似度分析
- ROI评估：营销投资回报率分析
- 智能补货：基于数据分析的库存管理
- 风险预警：供应链风险识别和预警
- 智能私信：个性化营销消息生成

## 技术栈

- React 18
- TypeScript
- Vite
- Tailwind CSS
- ECharts
- Lucide React

## 构建和部署

### 构建项目

```bash
# 进入app目录
cd app

# 安装依赖
npm install

# 构建项目
npm run build
```

### 部署到Gitee Pages

1. 构建项目生成dist目录
2. 将代码推送到Gitee仓库
3. 开启Gitee Pages服务，选择main分支和app/dist目录
